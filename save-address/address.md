

# SAVE ADDRESS 
- Rule [users] [what] [why]
  

**USER STORY**
  as a returning customer, i want the checkout page to remember my shipping address, so that i don't have to reenter it every time I order.

**ACCEPTANCE CRITERIA**

- saved address appears automatically on checkout for returning customers
- customers can edit the pre-filled address before order
- if no address is saved, the form behaves exactly as it does today .
