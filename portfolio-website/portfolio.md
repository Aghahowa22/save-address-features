
# MY PORTFOLIO WEBSITE


**USER STORY**
As a potential deveployer or client,
I want to view a developer’s portfolio, skills, projects, and experience,
so that I can understand their abilities and decide whether to work with or hire them.

**ACCEPTANCE CRITERIA**
- The  user can view the developer's About Me section.
- The user can view a list of skill and technology.
- The user can view completed projects with descriptions and links.
- The user can view developer's work, exprience or education.
- The user can access the developers conatact information.
- The website works well on mobile and desktop.
- The user can click to Github, Linkedin or live projects.
